# nb-information
> This component is only for [Vue.js 3+](https://vuejs.org/)

<br />

This lib contains information components.

## Installation

```bash
npm install @vlalg-nimbus/nb-information

# or

yarn add @vlalg-nimbus/nb-information
```

## Usage

```js
// main.js
import { createApp } from 'vue'
import App from './App.vue'

import NbInformationComponents from '@vlalg-nimbus/nb-information'
import "@vlalg-nimbus/nb-information/dist/style.css";

const app = createApp(App)
app.use(NbInformationComponents)
app.mount('#app')
```
