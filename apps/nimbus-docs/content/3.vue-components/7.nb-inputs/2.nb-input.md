This is an input component for [Vue.js 3+](https://vuejs.org/).

::NbInputsInputTest

## Installation

[`NbInput`](/vue-components/nb-inputs/nb-input) **masks** (`input-mask`) use [`vue-the-mask@0.11.1`](https://www.npmjs.com/package/vue-the-mask/v/0.11.1) as a **peer dependency** (versão fixada pelo `nb-inputs`; a lib não recebe releases novas). [`@vlalg-nimbus/magic-debounce`](https://www.npmjs.com/package/@vlalg-nimbus/magic-debounce) (e.g. `NbInputSearch`) remains a normal dependency of the package and does not require a separate install.

::code-group
  ```bash [Yarn]
  yarn add @vlalg-nimbus/nb-inputs vue-the-mask@0.11.1
  ```
  ```bash [NPM]
  npm install @vlalg-nimbus/nb-inputs vue-the-mask@0.11.1
  ```
::

## Usage

::code-group
  ```js [Vue 3]
  import { createApp } from 'vue'
  import App from './App.vue'

  import NbInputComponents from '@vlalg-nimbus/nb-inputs'
  import "@vlalg-nimbus/nb-inputs/dist/style.css";

  const app = createApp(App)
  app.use(NbInputComponents)
  app.mount('#app')
  ```
  ```js [Nuxt 3]
  import NbInputComponents from '@vlalg-nimbus/nb-inputs'
  import "@vlalg-nimbus/nb-inputs/dist/style.css";
  
  export default defineNuxtPlugin(context => {
    context.vueApp.use(NbInputComponents)
  })
  ```
::

To use, simply call the component, in this case it will be `NbInput` or `nb-input`.

## Events

| name    | Return type | Description |
| ------- | :--------- | :---------------------------- |
| current-value | value | Fired when the input value changes. With **`input-mask`**, shape follows **`input-mask-emit`**. With **`input-mask-external`**, the string your library passes to **`setMaskedValue`** (see **`mask-external-ready`**). Otherwise the raw value (and `number` typing rules apply). |
| changed | value | Same payload semantics as **`current-value`**. |
| focused | nothing | Fired when the input receives focus. |
| blurred | nothing | Fired when the input loses focus. |
| show-input-eye | boolean | Fired when the password visibility toggle is clicked, returns the visibility state. |
| clicked | MouseEvent \| KeyboardEvent | Fired when the input container is clicked. Receives the native DOM event as first argument. |
| entered | value | Fired when **Enter** is pressed in the field and the value is accepted. Same payload rules as **`changed`** / **`current-value`** (including **`input-mask`** + **`input-mask-emit`**). With **`input-mask`**, if the trimmed value is non-empty but does **not** fill every mask token slot, **`entered`** is **not** fired — see **`mask-error`**. |
| paste | value | Fired when content is pasted into the input, returns the pasted value as a string. Always fired, even when `blockPaste` is `true` (in which case the paste action is blocked but the event is still emitted). |
| mask-error | `{ reason, trigger, masked, clean, requiredTokenCount, filledTokenCount, activePattern }` | **Only with `input-mask`** (`input-type="text"`, not external). Fired when the **trimmed** value is non-empty but does **not** fill every mask token slot: on every **`changed`** (`trigger: 'changed'`) and when **Enter** is pressed (`trigger: 'enter'`). Same extra fields as [`NbInputChip` `mask-error`](/vue-components/nb-inputs/nb-input-chip#events), plus **`trigger`**. **`entered`** is not emitted when Enter would fire only `mask-error` (`trigger: 'enter'`). |
| mask-external-ready | `{ inputEl, registerSync, setMaskedValue }` | **Only with `input-mask-external`** (`input-type="text"`). Fired when the native input is mounted. Attach your mask library to **`inputEl`**. See [External mask](#external-mask-input-mask-external). |

## Input mask (`input-mask`)

Masking uses [`vue-the-mask@0.11.1`](https://www.npmjs.com/package/vue-the-mask/v/0.11.1) as a **peer dependency** — install it alongside `@vlalg-nimbus/nb-inputs` (see [Installation](#installation)). The `NbInput` module imports this package, so your bundler must be able to resolve `vue-the-mask` whenever you use `NbInput`, not only when `input-mask` is set.

### Rules

- **`input-type` must be `text`** — `input-mask` is ignored for `number`, `email`, and `password`.
- In templates, use the kebab-case attribute **`input-mask`**, which maps to the `inputMask` prop.
- With **`input-mask`**, the shape of values in **`changed`**, **`current-value`**, and **`entered`** follows **`input-mask-emit`**: **`masked`** (default), **`clean`**, or **`both`** (`{ masked, clean }`). See the prop table and the subsection below.
- Optional **`input-mask-tokens`**: merge extra [`vue-the-mask` tokens](https://www.npmjs.com/package/vue-the-mask) for patterns the defaults cannot express (e.g. optional leading minus). See [Custom mask tokens (`input-mask-tokens`)](#custom-mask-tokens-input-mask-tokens).
- Pass a **string** for a fixed pattern, or an **array of strings** when the mask length should change (e.g. landline vs mobile phone). Avoid `Object.freeze()` on arrays you pass in — `vue-the-mask` may sort patterns in place; `NbInput` already passes a shallow copy of arrays to the directive, but keeping mutable arrays in your code is simpler.

### Emit shape with mask (`input-mask-emit`)

Use the kebab-case attribute **`input-mask-emit`** on `NbInput` when **`input-mask`** is set:

| Value | `changed` / `current-value` / `entered` |
| :---- | :---------------------------------------- |
| `masked` (default) | Masked string (what the user sees). |
| `clean` | Unmasked / token-only string from `vue-the-mask`. |
| `both` | Object `{ masked, clean }`. |

Without **`input-mask`**, **`input-mask-emit`** has no effect.

### Pattern tokens (`vue-the-mask`)

Common placeholders (see the [package README](https://www.npmjs.com/package/vue-the-mask) for full list):

| Token | Meaning |
| :---- | :------ |
| `#` | Digit (`0-9`) |
| `A` | Letter (uppercase transform) |
| `a` | Letter (lowercase transform) |
| `S` | Letter (a-z, A-Z) |
| `X` | Alphanumeric |
| `!` | Escape next character (literal) |

Literal characters in the pattern (e.g. `.`, `-`, `(`, space after `R$`) are not special unless you use `!` where the library requires it.

### Custom mask tokens (`input-mask-tokens`)

The default tokens (`#`, `X`, `S`, …) cover many cases, but not everything — for example **`#` only matches digits**, so a **optional leading minus** for negative numbers is not expressible with the default set alone.

Use the **`inputMaskTokens`** prop (template: **`input-mask-tokens`**) to pass an object of **extra** token definitions. The component **shallow-merges** it onto [`vue-the-mask`’s default token map](https://www.npmjs.com/package/vue-the-mask): `{ ...defaultTokens, ...inputMaskTokens }`.

| Topic | Detail |
| :---- | :----- |
| **When to use** | You need a **new placeholder character** in the mask string (e.g. `N` for “minus or digit”) or you intentionally override a default (see warning below). |
| **Omit the prop** | Omit it or use `null` / leave the object **empty** — behaviour stays the same as before: only **`input-mask`** is passed to the directive and the library uses its built-in tokens. |
| **When the prop has keys** | `NbInput` passes **`{ mask, tokens }`** to `vue-the-mask` (same idea as its `TheMask` component). The **`masker`** used for **`input-mask-emit`** (`clean` / `both`) and for **`mask-error`** completion uses that **same merged** token map, so everything stays consistent. |
| **Merge semantics** | **Shallow** merge at the **top level** only. If you set a key that already exists in the defaults (e.g. `#`), **your entry replaces** the built-in digit token — usually you should use **new** symbols (`N`, `_`, …) instead of redefining `#`. |
| **Token shape** | Per the library: each key is **one character** used in the mask string; the value is `{ pattern: RegExp }` and optionally `transform`. |

**Example — signed integer (optional `-`, then up to three digits):** use one custom slot `N` (minus or digit) and three normal digit slots `#`:

```vue
<script setup>
const signedIntMaskTokens = {
  N: { pattern: /[-0-9]/ },
}
</script>

<template>
  <NbInput
    nb-id="signed-int"
    input-name="signed-int"
    input-type="text"
    input-mask="N###"
    :input-mask-tokens="signedIntMaskTokens"
    label="Signed value"
    :show-label="true"
  />
</template>
```

The same **`input-mask-tokens`** API exists on **[`NbInputChip`](/vue-components/nb-inputs/nb-input-chip)** for the chip text field.

### Examples

**CPF (fixed 11 digits)**

```vue
<NbInput
  nb-id="doc-cpf"
  input-name="cpf"
  input-type="text"
  input-mask="###.###.###-##"

```

**CEP**

```vue
<NbInput
  nb-id="doc-cep"
  input-name="cep"
  input-type="text"
  input-mask="#####-###"

```

**Brazilian phone (dynamic mask)**

```vue
<script setup>
const phoneMasks = ['(##) ####-####', '(##) #####-####']
</script>

<template>
  <NbInput
    nb-id="doc-phone"
    input-name="phone"
    input-type="text"
    :input-mask="phoneMasks"
    label="Phone"
    :show-label="true"
  />
</template>
```

**Currency with `vue-the-mask` (any locale, not recommended)** — [`vue-the-mask`](#input-mask-input-mask) fills **mask slots** as plain characters; it does not treat input as a **numeric amount** with a fixed decimal scale. Growing pattern arrays (prefix + grouped digits + decimal places) therefore behave like variable-length **strings**, not like money: extra digits often shift into the “cents” part of the pattern instead of growing the integer (e.g. with a `R$ #,##` … `R$ ###,##` progression, typing `100` can show `1,00` — the same class of issue appears with other separators, such as `$ #.##` for USD). For real **currency** fields (BRL, USD, EUR, …), use **[External mask](#external-mask-input-mask-external)** with a numeric mask library.

**Signed integer with custom token** — see [Custom mask tokens (`input-mask-tokens`)](#custom-mask-tokens-input-mask-tokens) above.

## External mask (`input-mask-external`)

Use this mode when [`vue-the-mask`](#input-mask-input-mask) is not enough — in particular for **currency**: fixed decimal scale (`scale: 2`), thousands separators, and locale-specific radix (`,` vs `.`). The limitation above is **not specific to Brazil**; BRL is simply a common case. You install and wire a third-party library in your app (this doc uses **[IMask](https://imask.js.org/)** as the reference implementation).

| Mode | Prop | Library |
| :--- | :--- | :------ |
| Built-in | `input-mask` | `vue-the-mask` (CPF, phone, CEP…) |
| External | `input-mask-external` | **Your choice** (IMask, AutoNumeric, …) |

### Currency with IMask

The reference composable supports **`'br'`** and **`'en'`** (`thousandsSeparator` / `radix` / `mapToRadix`). Examples below use **Brazilian Real (BRL)**; the same digit-entry rules apply for other locales if you adjust separators in the composable.

### Install IMask (in your app)

### Complete example (copy-paste)

Two files are enough: the composable below (same as in the monorepo at `packages/vue-components/nb-inputs/src/demo/useDemoImaskCurrency.js`) and a Vue component that wires `NbInput`. Interactive demo: `src/App.vue` → **“dois modos de máscara”** → **2) External**.

#### 1) `composables/useDemoImaskCurrency.js`

```js
import { ref, onUnmounted } from 'vue'
import IMask from 'imask'

export function useDemoImaskCurrency(locale = 'br') {
  const maskedDisplay = ref('')
  const cleanValue = ref('')

  let imaskInstance = null

  const prefix = locale === 'en' ? '$ ' : 'R$ '
  const separators =
    locale === 'en'
      ? { thousandsSeparator: ',', radix: '.', mapToRadix: ['.', ','] }
      : { thousandsSeparator: '.', radix: ',', mapToRadix: ['.', ','] }

  let skipRegisterSync = false

  const formatMaskCleanForCurrency = (value, loc) => {
    const masked = String(value ?? '').trim()
    if (!masked) return ''
    const decSep = loc === 'en' ? '.' : ','
    const decIdx = masked.lastIndexOf(decSep)
    if (decIdx !== -1) {
      const intPart = masked.slice(0, decIdx).replace(/[^\d-]/g, '')
      const decPart = masked.slice(decIdx + 1).replace(/\D/g, '')
      if (!intPart && !decPart) return ''
      if (!decPart) return intPart || ''
      return `${intPart || '0'}.${decPart}`
    }
    const digits = masked.replace(/[^\d-]/g, '')
    return digits || ''
  }

  const maskedToImaskValue = (masked) => {
    if (!masked || !String(masked).trim()) return ''
    const clean = formatMaskCleanForCurrency(masked, locale)
    if (!clean) return ''
    const num = Number(clean)
    return Number.isNaN(num) ? '' : num
  }

  let setMaskedValueOnInput = null

  const syncFromImask = () => {
    if (!imaskInstance) return
    const display = imaskInstance.displayValue
    const masked = display ? `${prefix}${display}` : ''
    const typed = imaskInstance.typedValue
    const clean =
      typed === '' || typed == null || Number.isNaN(Number(typed))
        ? ''
        : Number(typed).toFixed(2)

    skipRegisterSync = true
    maskedDisplay.value = masked
    cleanValue.value = clean
    setMaskedValueOnInput?.(display)
    queueMicrotask(() => {
      skipRegisterSync = false
    })
  }

  const attach = ({ inputEl, registerSync, setMaskedValue }) => {
    if (!inputEl) return

    setMaskedValueOnInput = typeof setMaskedValue === 'function' ? setMaskedValue : null

    imaskInstance?.destroy()
    imaskInstance = IMask(inputEl, {
      mask: Number,
      scale: 2,
      signed: false,
      normalizeZeros: true,
      padFractionalZeros: false,
      ...separators,
    })

    registerSync?.((masked) => {
      if (!imaskInstance || skipRegisterSync) return
      const next = maskedToImaskValue(masked)
      if (next === '') {
        imaskInstance.value = ''
      } else {
        imaskInstance.updateValue(next)
      }
      syncFromImask()
    })

    imaskInstance.on('accept', syncFromImask)
    syncFromImask()
  }

  const destroy = () => {
    imaskInstance?.destroy()
    imaskInstance = null
  }

  onUnmounted(destroy)

  return {
    maskedDisplay,
    cleanValue,
    attach,
    destroy,
  }
}
```

#### 2) `components/CurrencyNbInput.vue` (or your page)

Same wiring as the package demo: composable refs for display/API plus a ref fed by **`@changed`** so you can compare IMask output with what `NbInput` emits.

```vue
<script setup>
import { ref } from 'vue'
import { useDemoImaskCurrency } from './composables/useDemoImaskCurrency.js'

const demoImaskCurrency = useDemoImaskCurrency('br') // or 'en' → $ 1,234.56
const demoExternalMaskNbChangedLast = ref('')

const onDemoExternalMaskNbChanged = (v) => {
  demoExternalMaskNbChangedLast.value = v == null || v === '' ? '' : String(v)
}
</script>

<template>
  <NbInput
    nb-id="demo-mask-external-imask"
    input-name="demo-mask-external-imask"
    input-type="text"
    input-mask-external
    label="Amount (R$)"
    input-placeholder="0,00"
    :show-label="true"
    @mask-external-ready="demoImaskCurrency.attach"
    @changed="onDemoExternalMaskNbChanged"
  />
  <pre>IMask masked: {{ demoImaskCurrency.maskedDisplay || '(empty)' }}
clean (API): {{ demoImaskCurrency.cleanValue || '(empty)' }}
NbInput @changed: {{ demoExternalMaskNbChangedLast || '(empty)' }}</pre>
</template>
```

For **`input-mask`** + **`input-mask-emit="both"`** (e.g. CPF), use a separate handler — see [Emit shape with mask](#emit-shape-with-mask-input-mask-emit). The package demo uses `onDemoGenericMaskChanged` next to this block in `App.vue`; it is not required for currency / IMask.

### Typing behaviour (IMask `Number`, `scale: 2`)

Digits are entered **right-to-left** (cash-register style): the last two digits are always the fractional part, regardless of locale.

**BRL example** (`useDemoImaskCurrency('br')`):

| You type | Shown | `cleanValue` (API, always `.` as decimal) |
| :------- | :---- | :--------------------------------------- |
| `10000` | `R$ 100,00` | `100.00` |
| `123490` | `R$ 1.234,90` | `1234.90` |

With **`'en'`**, the same digit sequences format as `$ 100.00` and `$ 1,234.90`. You may also type `,` or `.` as the decimal separator (`mapToRadix` in the composable). A **digits-only** sequence is usually the most predictable in any locale.

### `mask-external-ready` payload

| Field | Usage |
| :---- | :---- |
| `inputEl` | Native `<input>` — pass to `IMask(inputEl, options)` (or your library’s equivalent). |
| `setMaskedValue(masked)` | Call from IMask’s **`accept`** handler with **`displayValue`** only (e.g. `1.234,90`), **without** a `R$` prefix. Updates **`changed`** / **`current-value`** without Vue overwriting the DOM. |
| `registerSync(fn)` | Only when **`input-text`** changes **from outside** (initial value, form reset). Inside `fn`, use `mask.updateValue()`, not `input.value =`. |

### Pitfalls

- Do **not** bind `:input-text="currencyMask.maskedDisplay"` on every keystroke — it loops with `registerSync`.
- Do **not** read `event.target.value` on native `@input` — the DOM value may exist **before** IMask clamps decimals (e.g. a third decimal digit).
- Do **not** pass the currency **prefix** (`R$`, `$`, `€`, …) into **`setMaskedValue`** — IMask owns the input text; show the symbol in the label or in `maskedDisplay` from your composable.
- In **`input-mask-external`** mode, `NbInput` does **not** set `:value` on the `<input>`; the external library controls the DOM.

### Programmatic value (`input-text`)

```vue
<NbInput
  input-mask-external
  :input-text="initialMasked"
  @mask-external-ready="currencyMask.attach"
/>
```

```js
// e.g. API returns 1234.9 → show "R$ 1.234,90"
const initialMasked = 'R$ 1.234,90'
```

`registerSync` in the composable above (`maskedToImaskValue` + `imaskInstance.updateValue`) handles this path — do not assign `input.value` directly.
